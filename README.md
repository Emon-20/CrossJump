# CrossJump
Open `index.html` in any browser (no build step). Deploy: push to a GitHub repo's `main` branch, enable Pages → Source: GitHub Actions; `.github/workflows/deploy.yml` publishes it.
Structure: `js/config.js` (levels), `engine.js` (rules), `ai.js` (alpha-beta AI), `ui.js` (rendering/animation), `main.js` (game flow).
